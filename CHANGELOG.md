# Changelog

## 0.1.0 — 2026-11-24

Primeira versão para uso pessoal.

- Painel responsivo em português e demonstração sem serviços externos.
- Lista de desejos, metas, pausa, filtros, busca local e comparação manual de ofertas.
- Histórico por loja e meta com frete informado opcional.
- PostgreSQL, API autenticada e worker BullMQ.
- Coletor JSON-LD experimental para domínios de quatro lojas brasileiras.
- Caixa de saída para Resend e Telegram, deduplicação e intervalo de 24h.
- Testes de domínio, integração PostgreSQL e navegador.
- README visual, capturas da aplicação, documentação técnica e CI.
